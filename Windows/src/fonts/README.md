# Rounded keypad typeface

Nunito is bundled unchanged for the rounded calculator keys. The app reads it
locally and needs no font download at runtime. Chinese UI uses the system font.

Source: https://github.com/google/fonts/tree/main/ofl/nunito
File: `Nunito[wght].ttf`, downloaded 2026-09-05 and stored as `Nunito.ttf`.
